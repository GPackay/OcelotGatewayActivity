Which requests does the gateway reject before they reach a service, and why?

The Ocelot API Gateway rejects unauthorized requests to protected endpoints, including creating, updating, or deleting products and retrieving orders, when the request does not include a valid JWT Bearer token. It also rejects excessive login requests with a 429 Too Many Requests response when the configured limit of five requests within the 10-second period is exceeded. Requests to routes that are not configured in the gateway are not forwarded to any downstream service. These restrictions help secure the services by enforcing authentication, limiting repeated login attempts, and controlling access to available endpoints. Public requests, such as retrieving the product list, do not require authentication.
